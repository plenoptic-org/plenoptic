# Synthesizing Adversarial Examples

The following notebooks demonstrate how to synthesize adversarial examples using Plenoptic. Adversarial examples are images with subtle, imperceptible perturbations designed to deceive a Deep Neural Networks into making an incorrect classification ({cite:alp}`Szegedy2013`, {cite:alp}`goodfellow_explaining_2015`). We show in these notebooks how adversarial examples can be conceptualized and generated as metamers of a different class or images that maximize an optimized metric in representational space, while minimizing changes in pixel space.
